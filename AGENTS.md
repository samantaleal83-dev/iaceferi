# Instrucciones del proyecto

- Al dirigirte al usuario, utiliza el tratamiento formal («usted») y evita el voseo.
- No ejecutes `git diff --check` después de cada pedido. Úsalo solo cuando sea necesario para validar cambios relacionados con espacios en blanco.
- No ejecutes `git status` después de cada pedido. Úsalo solo cuando sea necesario para revisar el estado del repositorio.
