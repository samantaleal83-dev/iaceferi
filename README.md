# Ceferi AI Tool Kit

Conjunto de herramientas IA para administrar https://ceferimates.com/

## Contenido

Actualmente hay dos skills

- [Community Manager](skills/ceferi-community-manager.prompt.md)
- [Anuncios de conversión](skills/ceferi-conversion-ads.prompt.md)

## Ejemplos de uso

### Community Manager

Usá esta skill para planificar y crear contenido orgánico para las redes de CEFERÍ. Algunos ejemplos de pedidos:

1. **Planificar contenido:** “Armá un calendario de publicaciones para Instagram de dos semanas. Quiero mostrar las materas y también darle visibilidad al resto del catálogo actual.”
2. **Crear una pieza:** “Escribí un guion breve para un reel que cuente cómo CEFERÍ empezó con los mates y hoy está poniendo el foco en el cuero. No anuncies productos nuevos ni fechas de lanzamiento.”
3. **Responder consultas:** “Redactá una respuesta amable para alguien que pregunta por el precio y los colores disponibles de una matera. No tengo esos datos confirmados; ofrecé verificarlos.”

### Anuncios de conversión

Usá esta skill para crear o mejorar anuncios con un objetivo de conversión definido. Algunos ejemplos de pedidos:

1. **Anuncio para compra:** “Creá un anuncio para Instagram que lleve a comprar una matera en ceferimates.com. No tengo una promoción activa; indicá qué información falta para publicarlo.”
2. **Anuncio para consultas:** “Proponé un anuncio para Facebook que invite a consultar por las materas disponibles. Incluí copy, título, CTA y destino, sin inventar precios ni stock.”
3. **Variantes para probar:** “Prepará dos enfoques de anuncio para una matera disponible: uno centrado en el uso cotidiano y otro en la idea de regalo. Explicá qué hipótesis prueba cada uno y no prometas resultados.”
